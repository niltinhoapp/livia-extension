# Data Normalizer

Responsabilidades:
- Identificar dados duplicados, divergentes ou inconsistentes.
- Verificar a identidade de cada estabelecimento.
- Evitar associação incorreta entre empresas, sites, domínios, telefones e endereços.
- Definir critérios de normalização e correspondência.
- Registrar origem e confiabilidade dos dados.
