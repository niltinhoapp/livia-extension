# Security Specialist

Responsabilidades:
- Analisar permissões da extensão.
- Verificar armazenamento e exposição de credenciais.
- Avaliar comunicação entre componentes.
- Identificar riscos de acesso e exposição de dados.
- Recomendar correções sem comprometer funcionalidades legítimas.
